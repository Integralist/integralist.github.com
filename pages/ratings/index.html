Ratings

What do the numbers mean?

All my reviews include a RATING underneath each match:

  1. Skip this match.
  2. This is a poor match and not worth your time.
  3. This is pretty bad and probably worth skipping if you’re short on time.
  4. This was OK but a bit of a chore to get through.
  5. This match is watchable, and possibly even enjoyable.
  6. This was an enjoyable match.
  7. This was a good match.
  8. This is a very good match.
  9. This is damn near perfection, so try and find time to watch it.
  10. You MUST watch this match as soon as possible.
